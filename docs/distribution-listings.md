# Distribution listings

The npm package exposes `merge-guard` from `src/cli.js`, requires Node 18+, and performs local diff analysis without runtime dependencies or credentials. The GitHub Action defaults to report-only behavior and requires only `contents: read`; comment writing is opt-in and requires `pull-requests: write`. SARIF is generated locally and is not uploaded automatically.

Support: see `CONTRIBUTING.md` and the issue tracker. Security: see `docs/security/vulnerability-response.md`. Privacy: selected diffs and reports are processed locally and are not uploaded by the scanner or Action.
