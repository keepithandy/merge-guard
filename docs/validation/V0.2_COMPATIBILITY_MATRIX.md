# v0.2 Compatibility Matrix

Tracking: #38 and #52

## Supported runtime

Merge Guard's documented minimum runtime is Node.js 18:

- `package.json` declares `"node": ">=18"`.
- The README states that Node.js 18 or newer is supported.

## Verified matrix

The consolidated v0.2 contract suite passed in [GitHub Actions run 32730957015](https://github.com/keepithandy/merge-guard/actions/runs/32730957015).

| Node.js | Ubuntu | Windows |
| --- | --- | --- |
| 18.x | Pass | Pass |
| 20.x | Pass | Pass |
| 22.x | Pass | Pass |
| 24.x | Pass | Pass |

Each matrix job is named `Node <version> on <operating-system>`, so any failure is attributed to an exact runtime and operating system.

## Commands exercised

Every matrix job runs:

```bash
npm install --no-package-lock --ignore-scripts
npm run smoke
npm run test:cli
npm run test:snapshots
npm run release:check
node src/cli.js --help
node src/cli.js examples/sample.diff
node src/cli.js --json examples/sample.diff
npm pack --dry-run
```

The same revision also passed the [standalone smoke workflow](https://github.com/keepithandy/merge-guard/actions/runs/32730957140) and [composite Action fixture](https://github.com/keepithandy/merge-guard/actions/runs/32730956991).

## Guardrail

These checks install and inspect package contents locally. They do not publish a package, create a tag, or create a GitHub release.
