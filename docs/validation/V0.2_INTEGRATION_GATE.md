# v0.2 Integration Gate

Tracking: #38 and #50

## Required commands

```bash
npm run smoke
npm run test:cli
npm run release:check
```

## Required CI coverage

- Node 18, 20, 22, and 24
- Ubuntu and Windows
- CLI help and sample diff
- JSON report generation
- package dry run

## Closure rule

Issue #50 closes only when the commands pass on the consolidated main branch, or every failure has a focused reproducible defect.

This gate does not publish packages, create tags, or create releases.
