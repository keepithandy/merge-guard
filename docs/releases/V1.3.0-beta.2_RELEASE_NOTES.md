# Merge Guard v1.3.0-beta.2 — experimental preview

Adds `merge-guard --version`, which prints `merge-guard 1.3.0-beta.2` without requiring a diff. This follow-up preserves report schema 1 and scoring behavior.

Requires Node.js 18 or newer. Validation covers Node 18/20/22/24 on Ubuntu and Windows. Download the release archive, verify it against SHA256SUMS, and install:

```powershell
Get-FileHash .\merge-guard-1.3.0-beta.2.tgz -Algorithm SHA256
npm install --global .\merge-guard-1.3.0-beta.2.tgz
merge-guard --version
merge-guard --help
```

The first pilot on an earlier product commit recorded a stop decision: actionable precision 12/140 (8.6%, against a 70% gate), supported-scope recall 12/35 (34.3%), and no measurable critical recall because there were no high-severity concerns. This CLI fix does not demonstrate improved accuracy. Keep human review and testing in place.

The archive is unsigned; checksums provide integrity checks, not a publisher signature. npm registry publication is not included. Preparation records preserve their build-time state; GitHub release metadata records publication separately.

Report issues at https://github.com/keepithandy/merge-guard/issues using minimal synthetic examples and omit private source, credentials, and pilot data. Remove a global installation with `npm uninstall --global merge-guard` or reinstall a previously verified archive to roll back.
