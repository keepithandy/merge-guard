# Merge Guard v1.3.0-beta.1 source release notes

Status: **unpublished beta source — preparation only**

These notes describe the current `1.3.0-beta.1` source. They do not prove approval, signing, tagging, npm publication, GitHub release creation, an Action-reference change, or a Marketplace listing.

## Highlights

- Deterministic doctor diagnostics and privacy-safe adoption guidance.
- Optional, explicit impact metadata with explainable direct, transitive, repository-wide, generated, partial, and unknown evidence.
- Strict prior-report/manifest verification and caller-owned CI artifact handoff.
- Resilient managed-comment, annotation, SARIF, comparison, threshold, and canceled-attempt projection states.
- Byte-stable durable review artifacts across Node 18/20/22/24 on Ubuntu and Windows.

## Compatibility

- Node.js 18 or newer is required.
- JSON report schema remains version `1`; v1 scoring and no-metadata behavior remain compatible.
- Starter policies and the reference plugin continue to support Merge Guard `>=1.0.0 <2.0.0`.
- New impact, prior-evidence, and projection contracts are explicit and additive.

## Beta purpose

This beta exists to validate usefulness, not to claim product-market fit. The next gate is a labeled historical-PR evaluation measuring actionable findings, noise, missed risks, setup effort, and runtime without telemetry or automatic repository upload.

## Known limitations

- Core scoring remains deterministic heuristic analysis and does not prove a change safe.
- Public npm installation is unavailable until separately approved and verified.
- Merge Guard does not execute suggested project commands, automatically fetch prior evidence, upload SARIF, or infer dependency graphs without explicit metadata.

## Recovery

Return to a reviewed immutable source or Action commit and rerun the documented gates. Registry changes, release edits, Action-reference repair, revocation, and user communication require separate owner approval.
